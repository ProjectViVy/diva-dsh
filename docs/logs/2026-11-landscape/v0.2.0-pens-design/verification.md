## 跑不了的验证

| 项 | 原因 | 何时补 |
| --- | --- | --- |
| 模拟器族可读性（RAM/输入） | 本机未装 RetroArch/BizHawk，且需要至少一个 ROM | 用户批准 M0 后 |
| WebSocket/CDP 对 canvas 游戏 | 需要有目标网页游戏 | M1 |
| 两 host 的 MCP 能力矩阵 | 需要 Codex/Hermes 实际运行 | M0 验收时 |
| 单轮 token 成本 | 需要真实 profile 与观察采样 | M0 验收时（预算护栏的实测值） |

## 反向验证（可选）

文档侧的「反向验证」：把设计里的「工具面恒定 4 个」与现状（淋雨家 9 个 MCP、Blender 32 工具）对照，确认这条约束确实来自测量而不是偏好；把「深度分级」与 PENS 原文「不能赋予宿主不具备的能力」对照，确认没有过度承诺。
