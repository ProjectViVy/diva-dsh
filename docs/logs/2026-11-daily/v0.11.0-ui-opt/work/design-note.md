# 日常界面 · 换肤为 Lumen 风格（设计说明）

> 2026-11-17。上一版（纸墨）留在 `css.next.txt`；本版是换风格，不是叠加。

## 来源与选择

参考 oil-ui-pro 作品库里的 **Lumen Studio · Design studio operations dashboard**
（https://ui.oiloil.org/works/lumen-studio/，封面保存在 `../evidence/reference-lumen.webp`）。

选择理由：

- 日常页是「对话 + 状态卡」的工作台，Lumen 是同一形状：左侧导航区、右侧内容区、白卡浮在暖灰画布上。
- 主色是珊瑚橙，和 DIVA 的品牌珊瑚有亲缘，落在现有产品里不突兀；同时和原来的纸墨气质明显不同。
- 它的层级靠字号、字重、留白和细发丝线，不靠纹理、手绘和不齐圆角，正好和上一版拉开。

备选（本轮不用，但可以切换）：Nightwatch（深色运维台）、Sonar（暖灰 + 深色栏的聊天）、Minutes（奶油纸 + 衬线标题的会议记录）。

## 改了什么

- 页面铺满暖灰画布；对话栏是一张白色圆角面板，右栏卡片白底细线软影。
- 气泡：她的浅灰、我的浅珊瑚；改为带一侧小圆角的 16px 现代气泡，去掉硬墨影。
- 页头只留一个 **diva.** 字标（衬线小写 + 珊瑚句点，参考 Lumen 的报头）；去掉星星方块、DI 头像和「主会话」副标题，状态是浅绿胶囊「在线」。
- 右栏：页签改成分段控件；日期分区头用等宽小字；徽标从手绘胶囊改成 6px 小圆角；进度条、图表、开关全部改珊瑚实色，不再用渐变。
- 空态、骨架、窄屏断点沿用上一轮（骨架三张、断点 940）。
- 左栏气泡补 Markdown：标题、列表（可嵌套）、引用、代码块、表格、分隔线、行内粗体/斜体/删除线/代码/链接；原始 HTML 当文字，链接只放行 http(s)/mailto。
- 所有 `--dl-*` token 名字保留，`card-guide` / `uiThemeVars` 不用改。
