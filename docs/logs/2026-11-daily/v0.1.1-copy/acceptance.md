# 「日常」· v0.1.1-copy · 验收

在已经 `npm run restart` 的宿主上，硬刷新（Ctrl+Shift+R）后按顺序看这五步。
任何一步不对，把那一步的截图发我，并按「期望」那句说明差在哪。

## 1. 左栏：独立、不在 VIVY心核、在「插件」之上

- 期望：左栏从上往下是 `相遇` → **`日常`** → `插件`（或与既有顺序一致的相邻位置），
  「日常」**不在** `VIVY心核` / `VIVY工具` 两个分组的标题下面，收起分组也不会消失。
- 常见不对：它被折进 `VIVY心核` 的最上面一行 → 说明宿主还是旧脚本，重启一次。

## 2. 点开「日常」：两栏都在

- 期望：左边是「Today / 11 月 14 日 · 周六」的对话栏（米色纸、圆角、墨影），
  右边是四页上下文栏（Today / 任务 / 记忆 / 能力），两栏之间有空隙，整页不出现滚动条
  （两栏各自滚动）。

## 3. 左栏：往下滚，卡片都在

- 期望顺序：问候 → `Today / 视觉设计 · 正在处理任务` 五项清单 → `任务 · 进行中 整理本周邮件与日程`
  → 我的气泡「帮我把下午的评审挪到 15:00…」→ 两条回复 → `等待你的确认 把设计评审挪到 15:00`
  （`待批准`、`14:00 – 15:00 → 15:00 – 16:00`、`批准改动` / `再想想`）→ `邮件 Alex 发来「办公室搬迁安排」`
  → `已完成 3 个步骤 · 09:42` → 底部 `问问 Today…` 输入框。
- 勾一下「整理设计工作」：圆圈变成对勾、文字划线；再点一下复原。

## 4. 右栏四页

- **Today**：`8:00 晨间简报` / `今天，11 月 14 日` / 一句话导语 → `身体信号` 四格
  （8 小时 14 分、83.6 毫秒、2,800 步、44 次/分）→ `进行中` 卡（今天 18:00 截止，3 / 5 步）
  → `接下来的安排` 三条 → `待你确认 1` → `进行中 2`（60% / 40%）→ `学校旅行准备` → `快速打开` → 底部说明。
- **任务**：`4 个任务`、`新建任务`、筛选条（全部/进行中/待确认/已完成）、四条任务卡。
  点「进行中」→ 只剩一条；点「全部」→ 回来。
- **记忆**：`灵感 3 条`（三张卡，每张有 `开始执行` / `查看依据` / `忽略`）→ `长期目标 3 个`
  （勾选步骤、进度、`调整目标` / `写一条进展`）→ `本周观察 三个监控`（数值、涨跌、一二三四五六日的柱子、`最近 7 天`、`详情`）。
- **能力**：`快速打开` 六格 → `已连接的应用` 五行 → `工作区设置` 三个开关（点一下会翻转）
  → `账户与支持` 四行 → 底部说明。

## 5. 皮是 DIVA 的

- 期望：暖白纸底、墨色文字、铅笔色细线、四角不齐的圆角、无模糊的墨影；
  渐变只出现在页头宝石标记、进度条填充和开关打开态上。
- 不应出现：蓝色系大面积色块（原型的 `#e8f2fb`）——记忆卡的图标底与「待确认」蓝标是原型
  的状态色，保留为小面积点缀；如果觉得其中某处与 DIVA 冲突，指出来我改。

## 我做不到的两件事

1. **重启**：本会话的 agent 就跑在 `dsh web` 那个进程里，`npm run restart` 会把它一起杀掉，
   所以这一步只能由你执行（`npm run restart`，约 5 秒）。
2. **看真像素**：GUI 需要带 `?token=` 的地址，这一轮还是拿不到。离线 Chrome 的四页截图在
   `.artifacts/dsh-daily-check/new-*.png`，可以先对着看。
