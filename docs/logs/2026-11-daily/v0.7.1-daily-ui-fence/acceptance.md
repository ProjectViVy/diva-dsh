# 验收：左栏 dsh-ui 围栏

主人原话（转述）：「在普通 session 里面生效，但是日常中不生效。」

| 验收点 | 结果 | 证据 |
| --- | --- | --- |
| 日常左栏 assistant 气泡里的 `dsh-ui` 围栏渲成卡片 | 通过 | `spec-fence-01-daily-left.png` / `02-crop.png`，`.dl-spec` 4 个 |
| 卡片是 genui 同一套 spec（标题、bars、表格都对） | 通过 | 根标题「今天三件事」、写作 6 / 调试 3 / 复盘 2、表格 写完 3 / 完成 1 |
| 卡片外的正文照常显示 | 通过 | 截图里卡片上下都有原句 |
| 围栏代码本身不在正文里露出来 | 通过 | assistant 气泡 ``` 计数 0 |
| 一条回复多段围栏各成一张卡 | 通过 | 单测「多段围栏」；截图里一张回复一张卡 |
| 坏 JSON / 一个能画的节点都没有 → 退回原文 | 通过 | 单测「画不出来就降级」 |
| 没闭合的围栏不吞后面的正文 | 通过 | 单测「没闭合」 |
| html 围栏那条路没被踩坏 | 通过 | 翻开关回归 44/0/2 |
| 不重启宿主（3082 不断） | 保持 | 全程没碰 3082；隔离实例另起 3083，跑完已停 |
| 普通会话里的表现不变 | 通过 | `spec-fence-03-normal-session.png`，`.genui-dom-fence` 4 个 |

未达成的验收（本轮不做）：

- 左栏里点卡片按钮触发 `[genui-action]`：不支持（设计边界，见 summary.md）。
- 表单类节点（输入框、选择、开关动作、tabs 等）：不支持，节点被丢，兄弟节点照常。
