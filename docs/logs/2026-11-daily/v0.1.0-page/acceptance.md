# 「日常」页面插件（dsh-daily）· v0.1.0-page · 验收

刷新页面后按顺序走。哪一步不对就把那一步的截图和浏览器控制台里的红字一起发我。

## 1 入口在不在、位置对不对

左栏从上往下应当是：**相遇**（若舞台已注册）→ **日常** → **插件** → 自动化任务 …
- 「日常」**不能**被折进 `VIVY心核` / `VIVY工具` 分组里 —— 它必须是一条独立的行，和「插件」同级。
- 图标是一枚「日出越过地平线」的描边（16×16），文字「日常」。

## 2 点开：今天

页头（`DIVA · 日常` / 大标题「日常」 / `11 月 14 日 · 星期六 · 今年的第 318 天`）右侧是
三个标签页 + 一个描边的「写一笔」按钮。没有别的按钮。

- 三张标签页：**今天** / **本周** / **记录**，选中项有大号渐变填充块。
- 虚线偏好条：「今天的偏好：先把要动手的做完，再回消息。」
- 三格统计：`4 件 · 今天要做`、`2 小时 40 分 · 专注过`、`3 笔 · 记下来的`。
- 「三条线从八点铺到九点半」：8–21:30 的轴，5 个刻度（8/11/14/17/20），三行（手上的事 / 身体 / 人），
  条形分 `done`（实心墨）/ `now`（渐变 + 竖线游标）/ `later`（斜纹）。**条形不能越出卡片右边**。
- 「身体信号」：四行（睡眠 / 心情 / 步数 / 屏幕），有刻度的走条、没刻度的走点；右上一个计数徽标。
- 「今天要做」：4 条，点勾选框应翻转（勾上出现手绘勾、文字变淡）。
- 「今日一句」：左边一条粗标记，右边两行手写体。
- 整页只在面板内滚动，不带动整页。

## 3 本周

- 大卡「这一周不均匀，中间塌下去一格」：七格（一…日），每格一条竖轨 + 日期数字 + 底下「N 条」。
- **今天那格**写「今天」，边框变暖、底色是极淡的渐变；只有一格这样。
- 「这周的三件事」+「本周一句话」两列。
- 切回「今天」，刚才勾的那条仍保持勾选。

## 4 记录

- 「随手写一笔」：输入框 + 实心「记下」；输入为空时「记下」是禁用态（半透明、按不动）。
- 下面 3 条样本；打一句话按回车 → 立刻多出一条在最上面，输入框清空，计数从 3 变 4。
- 提示行写着「回车就记下。这一版只记在这一页里，刷新就散。」

## 5 页头「写一笔」

- 在「今天」或「本周」点它 → 跳到「记录」并把光标放进输入框。
- **已经在「记录」时再点**：光标也要落进输入框（这条是本轮修过的 bug）。

## 6 皮肤与窄窗

- 当前皮肤是 `diva`：页头标题应是墨色、**不是**渐变；卡片有 2–3px 无模糊的墨影与不齐圆角；
  主卡（今天那条偏好条所在卡）外面还有一圈转了一点点的第二道轮廓。
- 把窗口收窄到 ~1024：两列区域叠成一列，标签页不溢出、不挤成两行。
