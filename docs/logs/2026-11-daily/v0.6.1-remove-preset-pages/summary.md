## 改了什么

1. **Today**：删 `DAILY_CARDS`——两张带「示例」角标的示例卡（今天天气 / 每日推荐）连同晨间简报、身体信号、进行中、接下来的安排、待你确认、运行中、学校旅行、快速打开整组演示卡；只为它们存在的 `DEMO_COVER`（本地 SVG 配图）、`FOOT_TODAY`、`dayStamp()` 一并删掉。没人写今天那一页时，右栏只留标题条「今天的界面 · 还没有人写」+ 一句空态「她写好今天那一页之后，这里会自己出现。」。
   **worker 写的页面那条路原样保留**（沙箱 iframe + 高度回报 + 「刷新」按钮）：它是真数据源，不是预制内容。
2. **任务**：删 `TASKS`（四条演示任务、假计数「4 个任务 / 2 个进行中或待确认 / 4 个结果」、假进度、假提示）与 `taskCards()`；筛选器（`segmented-control`）与 `filter` state 一起退场——空列表上摆筛选器等于摆假交互。现在只剩「任务 / 还没有接数据源」+ 一句空态「她接下任务之后，这里会列出来。」。
3. **顺手删掉只服务于上述演示内容的 8 个 spec 小工厂**（`stat` / `kv` / `grid` / `prog` / `li` / `btn` / `h3` / `ghost`）与 `statusTone`；`t` / `badge` / `card` / `row` / `spacer` 保留，悄悄话占位页与两个空态都在用。
4. **没动的**：三个页签（Today / 任务 / 悄悄话）、页签切换、左栏聊天、`html` 围栏沙箱、折叠、悄悄话页、宿主半边 `index.js`、`GET /dsh-daily/api/today` 与 `$DSH_HOME/today/<date>.html` 的约定。

## 影响面

- 用户可见：Today 与任务两页变空（这正是要求）；悄悄话与左栏不变。
- 数据：无新增请求、无新文件；Today 仍只问一次宿主。
- 颜色与观感：两个空态都走 vendored 渲染器，只吃 `var(--dl-*)`；没有写死色值、没有 emoji、没有新示例。
- 依赖方：genui 渲染器（19 种节点）原样保留。
- 重启要求：**无**（纯浏览器半边）。
- 体积：`client.js` 1954 → 1802 行（−152，diff +40 / −192）；测试 1019 → 982 行。

## 取舍（多快好省）

最简方案就是「删数据、留结构、给一句话」，选它是因为要求是去掉假内容，不是重做页面。备选是「保留空态骨架 + 空筛选器 / 空新建按钮」——没选：没有任务时筛选没有对象，按钮也没接任何动作，等于把假交互留下来，与「验证期页面没必要存在」相冲。没有加任何新依赖、新配置或新样式。
