# 验收清单 v0.6.0（卡片品味）

**不用重启**：`client.js` 硬刷新即可；skill 已经装好（可用列表里能看到 `card-guide`）。

## A. 她画出来的卡，该像这页的一部分

- [ ] 在左栏说：「用 html 围栏给我画一个今天的三件事」。
- [ ] 卡片里的标题、正文、细线是**这页的墨色和纸色**，不是浏览器默认的黑白。
- [ ] 卡片没有硬编码色块：让它画一个进度条，应该是橙→珊瑚的渐变，不是纯红或纯蓝。
- [ ] 卡片看起来「薄」：没有大阴影、没有发光、没有一堆圆角叠着。

## B. 排版已经由宿主负责

- [ ] 卡片里只写 `<h2>` / `<table>` / `<blockquote>`，不写字号行高，出来也是整齐的（不像浏览器默认的衬线大字）。
- [ ] 表格有细下划线、表头是灰墨色、最后一行没有线。
- [ ] `<code>` / `<pre>` 是浅纸底 + 细描边，不是黑底白字。

## C. 指南有没有被她读到

- [ ] 让她画之前先问一句「你知道该用什么变量吗」。如果她答不上来，说明 `skill` 没加载——这时说一句「先 load card-guide」再试。
- [ ] 她画完之后，检查有没有犯指南里的禁令：emoji、`position:fixed`、外链图片、写死颜色、`<html>` 标签。

## D. 高度

- [ ] 短卡片（两行字）框高贴着内容，下方没有大片空白。
- [ ] 长卡片长到 620 就在框里滚，不会把整个聊天顶走。
- [ ] 刷新页面后卡片还在（围栏文本存在消息里，重新渲染即回来）。

## E. 不牵连

- [ ] 普通回复（没有围栏）不长框。
- [ ] 右栏三页照旧。

## F. 按钮（T2a：只填不发）

- [ ] 让她画一个带 A/B 两个按钮的卡片。
- [ ] 点 A：**输入框里出现一句第一人称的话**，光标在里面，**没有自动发出去**。
- [ ] 输入框里先打几个字，再点 A：新的话**另起一行**，原来的字还在。
- [ ] 点了一个按钮，然后按退格删掉——除了输入框，什么都没发生（没有工单、没有派活）。
- [ ] 点按钮前把卡片滚出视野、或切到别的会话再回来点，不报错。

## 结论

- 全绿 → 这条收 `done`。下一步只剩一件：**要不要在 master 提示词里加一句「想画界面时先 load card-guide」**——那是「她会不会主动画」的开关，不是技术问题。
- A 组某项不对（颜色不对）→ 说明 `uiThemeVars()` 在真页面里没采到：先看浏览器控制台有没有异常，再确认 `.dl` 存在；这是本轮唯一没在真 DOM 上验过的环节。
- F 组某项不对（点了没反应）→ 先确认卡片里的 `onclick` 写的是 `parent.postMessage({dlUiPick:'…'},'*')`（少写 `parent.` 就成了框内自己收，不会有反应）。
- 回滚：删 `UI_TOKENS`/`uiThemeVars`，`uiDocument` 回到单参数；删 `uiPickText`/`deliverUiPick`/`setUiPickSink` 与 `inputRef`；删 `skills/card-guide/` 与 `PROJECT_SKILLS` 里的名字。
