# 验收

## 手动（刷新即可，不用重启宿主）

1. 在 `http://127.0.0.1:3082` 硬刷新（Ctrl+Shift+R）——`client.js` 是浏览器半身，页面加载时重新装配。
2. 看左栏「相遇」下面那一行：图标应是**咖啡杯**（杯身 + 右侧把手 + 三缕热气），右边仍是「日常」二字。
3. 收起左栏到 36px 竖条：那一行只剩 18px 图标，仍应读成咖啡杯，不糊、不裁边。
4. 点这一行：仍切到「日常」页，选中态（浅色底）不该把图标盖掉。

## 通过标准

- 图标是咖啡杯，不是日出/太阳/硬币；
- 粗细与同一列相邻图标（插件、VIVY心核表头的爱心、VIVY工具表头的扳手）一致；
- 行高、间距、文字位置与改动前一致（只换图形，不换几何）。

## 回退

把 `plugins/dsh-daily/client.js` 里 `DailyIcon` 的 4 条 `path` 与 `viewBox/strokeWidth` 换回 16 格日出那三行即可（本目录 `summary.md` 记了原来那三条 `d`）。刷新页面。
