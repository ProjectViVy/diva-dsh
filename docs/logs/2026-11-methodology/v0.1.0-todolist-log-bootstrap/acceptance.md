# 验收步骤 v0.1.0

> 用户视角：点哪里、看什么、什么算通过。

## 前置

- 在 `diva-dsh/` 根目录新开一个 DSH 会话（不要复用当前会话）。
- 不需要启动任何服务；本次只涉及文档。

## 步骤

1. 新会话里第一句只说「继续」。
   - 预期：agent 读 `TODOLIST.md` 的 `NOW`，发现是「无」，于是问你要做什么；**不应**自行挑一个任务、也不应从旧文档里猜。
   - 实测：<待填>

2. 给它一个真实小任务（例如「修 docs 里某个失效链接」）。
   - 预期：动手前先把条目写进 `TODOLIST.md`（编号 `DV-`、`sev`、`Scope`、`日志:`），而不是直接改文件。
   - 实测：<待填>

3. 让它收工。
   - 预期：`TODOLIST` 状态更新；`docs/logs/` 出现对应的版本目录与四件套；`summary.md` 前 6 行块完整；「未验证」不是空话。
   - 实测：<待填>

4. 再新开一个会话，只说「继续」。
   - 预期：agent 在 3 次工具调用内说出：条目 id、上一轮做了什么、下一步具体动作、验收条件。
   - 实测：<待填>

## 不通过时怎么反馈

把该会话的前几次工具调用、以及它读到的 `TODOLIST.md` / 日志目录内容发回来，说明是哪一步断的（没读到文件 / 读到了但没照做 / 照做了但格式不对）。
