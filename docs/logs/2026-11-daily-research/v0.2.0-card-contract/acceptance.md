## 拍板后的验收（实施阶段）

- P1 装 genui 后：聊天里 ```` ```dsh-ui ```` 围栏真渲染；`render_ui` 出工具行卡；点卡内按钮会在会话里产生一条用户消息。
- P2 薄渲染器：喂一份 genui 合法 spec，页面卡渲染出 ≥6 种节点；未知节点静默跳过、不白屏。
- P3 storage 域：`card_save` 后重开页面，卡片仍在；`card_list` 能列出内置模板与用户保存的卡。
- P4 视觉：页面卡在纸墨下可读（不出现默认蓝底/圆角冲突），深浅色都可读。
- P5 回归：未装 genui 时页面仍能显示卡片（薄渲染器不依赖它）。
