1. §0 三条直答能独立读懂：能不能升、影响到哪、补丁路线成不成立。

4. §7 的 D1–D5 每题都有推荐项与备选，且写明「不拍板不实施」。

5. 观测（命令输出 / 官方 release 原文 / raw 源码）与推断、未核实分开；§8 不得混入结论段。
