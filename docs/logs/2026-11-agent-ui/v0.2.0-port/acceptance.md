## 2. 实施验收（拍板后）

### 若做 P0+P1（设计语言 + 原语）

- A1 新卡片在浅色/深色主题下都用 `--dsw-*` token，无字面色；`pnpm run verify-client-ui-i18n` 通过。
- A2 文案全部来自 locale 字典，无硬编码中文/英文。
- A3 `pnpm run test:gui` 绿；截图与 OpenMuse 参考图并排比对（圆角、间距、按钮高度）差异可解释。

### 若做 P2（卡片集合）

- A4 每张卡在 `preparing` / `running` / `success` / `failure` / `cancelled` 五个相位都有明确形态；畸形数据落 generic 不白屏。
- A5 卡片只用 `tool/call`、`tool/result` 数据派生；刷新与重放后一致。

### 若做 §5（widget 资产）

- A6 一个 composed widget 能由 agent 生成、保存为资产、在会话中渲染；重开 GUI 后仍在。
- A7 未知词汇 / 超限文档 / 非法 props → 降级为文本，且不抛错、不白屏。
- A8 资产 id 引用与内联快照并存时，历史卡片不因资产被编辑而改变。
- A9 `Button.action` 回流只接受 `{id, payload}`，host 侧校验，未命中白名单直接拒绝。
- A10 文档 2–4KB 时，检查一次 turn 的 token 增量与 KV 缓存命中（记录实测数字，不靠猜）。
