# dsh-see-now · v0.3.2-panel-review · 验收

> 前置：`npm run stop && npm start`（补丁在子模块工作区里，宿主不会热加载），然后 `Ctrl+F5`。

1. 打开 `VIVY心核 → 我看到了 → 调试`。
2. 点「开始看」，等 5 秒。**「实时状态」最上面应出现一句彩色结论**，而不是只有一堆数字：
   - 静止的桌面应显示：「抓了 N 帧，一帧都没留下 —— 画面没变化，不出图是正常的。」
   - 若一帧都没抓到：显示「一帧都没抓到：先看下面的「最近错误」」。
3. 核对新增的计数：`留下的帧`、`判据 切/标/底`、`重复跳过`、`分数 均/最高`、`档位分布`、`首帧至今`、`叫醒空手`、`预留图`、`溢出`。
4. 切到有变化的视频/幻灯片，再等 3–5 秒：
   - `留下的帧` 应从 0 开始增长；
   - `帧 / 出图` 的「张」应 ≥1，结论变成「已出 N 张图」；
   - 若 `留下的帧 > 0` 但「张」仍为 0，结论会显示「还没封箱成图」，说明只是没到封箱条件。
5. 点一次「停止」：提示条应在约 4 秒后自己消失（不再一直挂着）。
6. 把窗口切到后台、等 10 秒再切回来：调试页不应出现长时间空白或卡顿（后台轮询已跳过）。
7. 隐私页按钮文案应为「停止采集与陪看」，与它的实际行为一致（不会关闭悬浮窗）。

**通过判据**：第 2 条那句结论出现，且第 4 条的「张」在变化画面上能从 0 变 1 以上。若第 4 条仍为 0，把调试页展开的「原始状态」整段贴回来——现在的计数足以定位是没留帧、没封箱，还是取图失败。
