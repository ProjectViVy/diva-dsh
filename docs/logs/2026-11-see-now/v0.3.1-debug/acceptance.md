# dsh-see-now · v0.3.1-debug · 验收

1. 打开 `VIVY心核 → 我看到了`，导航里应有 **调试**。若没有，`Ctrl+F5`；仍没有就重启 host。
2. 点「开始看」（任意页都行）。成功后面板应**自动切到调试页**，并出现「开始看：完成」。
3. 看「实时状态」：
   - `采集：在跑`；
   - `源：screen`；
   - `帧 / 出图` 的帧数应持续增长；
   - `已运行` 每 1.5 秒刷新一次；
   - 窗口/循环/听声音按实际情况显示。
4. 切到有变化的视频或幻灯片，等 2–3 秒，看 `出图` 是否从 0 变成 1 以上。**静止画面 0 张是正常的**。
5. 点「停止」，应回到 `没在看`、`采集收工`；调试页仍可打开，但采集停后不再需要轮询。
6. 若帧数不涨：
   - 看调试页「最近错误」；
   - 展开「原始状态」，把 `capture.lastError`、`capture.source`、`capture.pending` 记下来；
   - 再查 ffmpeg 是否在 PATH。
7. 调试页只读，不提供改配置；改配置仍走「配置」页。

**通过判据**：调试页存在；开始后自动切换；帧数有变化；停止后状态回落。出图与 token 另按 v0.3.0 的验收第 7 条继续。
